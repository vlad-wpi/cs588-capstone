version of the same run, and `tests/test_evaluation_results.py` for the regression
floors checked against it.

**Not the deployed model.** This evaluation measures the dev model: fit on Jan-Oct (subsampled, stratified by airport), calibrated on a held-out 10% slice of Jan-Oct, and scored on the full Nov-Dec test set. It is NOT model.pkl. The deployed model (`python -m src.train --save-model`) is fit on all twelve months with no chronological holdout, so it has no held-out data left to score honestly -- these figures stand in for it.
